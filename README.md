# Harbor City Hustle

A browser open-world street game you can install to your home screen.

Play: https://bruceai-hub.github.io/harbor-city-hustle/

Oculus Beta (WebXR for Meta Quest): https://bruceai-hub.github.io/harbor-city-hustle/oculus/
Quest Beta APK (for sideloaders; opens the Oculus Beta in the Quest Browser): https://bruceai-hub.github.io/harbor-city-hustle/downloads/HarborCityHustle-QuestBeta.apk


GitHub: https://github.com/BruceAi-hub/harbor-city-hustle

On your phone, open the Play address, then use **Add to Home Screen** (Safari share menu, or Chrome menu > Install app). It then opens full screen and works offline.

Android APK (v1.4): https://bruceai-hub.github.io/harbor-city-hustle/downloads/HarborCityHustle.apk

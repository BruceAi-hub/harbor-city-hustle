# Harbor City Hustle

A browser open-world street game you can install to your home screen.

Play: https://bruceai-hub.github.io/harbor-city-hustle/

Cloud play (Beta): https://bruceai-hub.github.io/harbor-city-hustle/cloud.html
Opens a helper page that copies the game address and launches the free browser.lol cloud browser; paste the address there to play, so even a slow PC can run it. The cloud browser may not have graphics acceleration, so the game can run choppy, and you may have to wait in a queue.

GitHub: https://github.com/BruceAi-hub/harbor-city-hustle

On your phone, open the Play address, then use **Add to Home Screen** (Safari share menu, or Chrome menu > Install app). It then opens full screen and works offline.

# Harbor City Hustle

A browser open-world street game you can install to your home screen.

Play: https://bruceai-hub.github.io/harbor-city-hustle/

Cloud play (Beta): https://browser.lol/create?url=https://bruceai-hub.github.io/harbor-city-hustle/
Runs the game in a free browser.lol cloud browser and streams it to you, so even a slow PC can play. The cloud browser may not have graphics acceleration, so the game can run choppy, and you may have to wait in a queue.

GitHub: https://github.com/BruceAi-hub/harbor-city-hustle

On your phone, open the Play address, then use **Add to Home Screen** (Safari share menu, or Chrome menu > Install app). It then opens full screen and works offline.

# Harbor City Hustle

A browser open-world street game you can install to your home screen.

Play: https://bruceai-hub.github.io/harbor-city-hustle/

Cloud play (Beta): https://www.browserling.com/browse/win10/chrome125/https://bruceai-hub.github.io/harbor-city-hustle/
Runs the game in a free Browserling cloud browser and streams it to you, so even a slow PC can play. Free sessions last a few minutes, and the cloud browser may not have graphics acceleration, so the game can run choppy.

GitHub: https://github.com/BruceAi-hub/harbor-city-hustle

On your phone, open the Play address, then use **Add to Home Screen** (Safari share menu, or Chrome menu > Install app). It then opens full screen and works offline.
